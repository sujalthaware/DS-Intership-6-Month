Week 1 – Python Basics and Data Processing
Project: Live Temperature Reader

This project is a beginner-level Python program that retrieves the current weather information for Nagpur, India using the OpenWeather API.

Objectives
Learn Python variables and data types.
Practice input and output.
Understand conditional statements.
Practice basic data processing.
Learn how to use a Python library (requests).
Retrieve live weather data from an API.
Technologies Used
Python 3
requests library
OpenWeather API
Installation

Install the requests library:

pip install requests
How to Run

Run the Python file:

python Basic_Data_Processing.py

The program retrieves the current temperature and weather description for Nagpur.

Example Output
City: Nagpur
Current Temperature: 28.5 °C
Weather: overcast clouds
Python Concepts Practiced
Variables
Data types
Operators
Input/Output
if-else conditions
Loops
Lists
Basic data processing
API requests
Important

Do not publish your OpenWeather API key on GitHub or share it publicly. For a real project, store the API key in an environment variable instead of directly inside the Python file.
